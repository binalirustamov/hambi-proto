# hambi — кликабельный прототип

Мобильный прототип суперапа hambi (iPhone-first). В репозитории лежит только собранная и обфусцированная версия — исходники не публикуются.

**Открыть:** https://binalirustamov.github.io/hambi-proto/

**English version:** https://binalirustamov.github.io/hambi-proto/en/

Лучше всего смотреть с iPhone: Safari → «Поделиться» → «На экран Домой». Все данные вымышлены.
